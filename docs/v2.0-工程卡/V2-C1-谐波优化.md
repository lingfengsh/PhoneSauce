## 2. fminsearchbnd 复刻规格

蓝本核心语义（施工者必须先读 `fminsearchbnd.m` 全文再动手）：

1. **变量变换**：无界参数 x → 有界参数 `xreal = fmin + (fmax-fmin)*(sin(x)+1)/2`；初值反变换 `x0 → asin(2*(x0-fmin)/(fmax-fmin) - 1)`。读蓝本核对是否含 clamp/NaN 特判（蓝本对 fmin=-Inf/fmax=Inf 的分支**不实现**——本项目两界均有限，卡里明确：两界必须有限，否则 raise）。
2. **优化器**：MATLAB `fminsearch`（无界 NM）→ `scipy.optimize.minimize(method="Nelder-Mead")`。默认参数对齐：`xatol=1e-4, fatol=1e-4`（MATLAB TolX/TolFun 默认）、`maxiter=maxfev=200*len(x0)`（MATLAB 默认）。蓝本若在 fminsearchbnd 内改了默认值，以蓝本为准。
3. 目标函数包装：目标 = `func_EstMaxVal`（见 §3），fminsearchbnd 只做变换不管目标。
4. 返回 `(x_at_bound_real, fval)`（变换回实域）。

签名：
```python
def fminsearchbnd(fun, x0: float, fmin: float, fmax: float) -> tuple[float, float]:
    """[x, val] = fminsearchbnd(fun, x0, LB, UB, options)（单变量版）。返回 (x_real, fval)。"""
```
测试锚点（`test_fminsearchbnd.py`，禁改）：
```python
import numpy as np
from backend.pysauce.fminsearchbnd import fminsearchbnd


def test_quadratic_inside_bounds():
    # 目标 (x-3.7)^2 在 [0,10] → 最优点 3.7
    x, val = fminsearchbnd(lambda t: (t - 3.7) ** 2, 5.0, 0.0, 10.0)
    assert abs(x - 3.7) < 1e-3
    assert val < 1e-5


def test_optimum_at_bound():
    # 最优点在边界 → sin 变换收敛到边界（值可无限逼近）
    x, val = fminsearchbnd(lambda t: (t - 0.0) ** 2, 5.0, 0.0, 10.0)
    assert abs(x - 0.0) < 1e-2


def test_unimodal_cosine():
    # cos 在 [2, 4] 内最小于 3π/2≈4.712? 不在窗内 → 最小在边界 4（cos 递减）
    x, val = fminsearchbnd(lambda t: np.cos(t), 3.0, 2.0, 4.0)
    assert abs(x - 4.0) < 1e-2 and abs(val - np.cos(4.0)) < 1e-6
```

## 3. get_h1_h2_h4 规格

蓝本要点：
- **2.0 范围裁剪**：只实现 `nargin==5` 整段分支（L26–69）；TextGrid 分段分支（L83–162）**不在本卡实现**——由 F1 编排层负责分段（v2 架构决定，注释注明）。`handles`/isComplete/stop-button 逻辑（L57–60）不实现（无 GUI）。
- 帧循环骨架与 Energy 相同：`ks=mround(k*sampleshift)`、`N0=Fs/F0`、`ystart=round(ks-1.5*N0)`、`yend=round(ks+1.5*N0)-1`（**N_periods=3，不是 EC 的 5**）、边界 continue。注意蓝本 L38 还要求 `F0_curr==0` 时 continue。
- 每帧调 `func_GetHarmonics(yseg, f_est, Fs)` 三次（f_est = F0/2F0/4F0）：
  ```
  df_range = round(f_est*0.1)          # MT-L177
  在 [f_est-df_range, f_est+df_range] 内最大化 EstMaxVal
  EstMaxVal: v = exp(-1j*2*pi*x*n/Fs)  # MT-L196，n=0..len(data)-1
             val = -20*log10(abs(data @ v))  # MT-L197，data·v 是点积（Goertzel 单点 DFT）
  h = -val（dB 幅度）; fh = 优化器返回的频率
  ```
  → Python：`fminsearchbnd(lambda fr: -20*np.log10(abs(np.dot(data, np.exp(-1j*2*np.pi*fr*n/Fs)))), f_est, f_min, f_max)`，`h = -val`。
- 输出 `(h1, h2, h4)` 三个 len(F0) 向量，NaN 填充。

签名：
```python
def get_harmonics(data: np.ndarray, f_est: float, fs: float) -> tuple[float, float]:
    """[h, fh] = func_GetHarmonics(data, f_est, Fs)。"""

def get_h1_h2_h4(y: np.ndarray, fs: int, f0: np.ndarray,
                 n_periods: int = 3) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """[H1, H2, H4] = func_GetH1_H2_H4(y, Fs, F0, ...)（整段分支）。"""
```

# -*- coding: utf-8 -*-

import os

import numpy as np

from backend.pysauce import framing
from backend.pysauce.get_h1_h2_h4 import get_h1_h2_h4, get_harmonics

FIX = os.path.join(os.path.dirname(os.path.abspath(__file__)), "fixtures")


def test_get_harmonics_sine_peak_at_fundamental():
    # 100Hz 正弦 5 周期：f_est=100 附近优化器应停在 ≈100
    fs = 16000
    t = np.arange(800) / fs
    x = 0.5 * np.sin(2 * np.pi * 100.0 * t)
    h, fh = get_harmonics(x, 100.0, fs)
    assert abs(fh - 100.0) <= 10.0 + 1e-6   # 搜索窗 ±10%
    assert h > 20 * np.log10(0.5 * 800 / 2) - 6   # 单点DFT 峰≈N/2·A，dB 量级 sanity（±6dB）


def test_h1h2h4_harm5_shapes_and_range():
    y, fs = framing.read_wav(os.path.join(FIX, "harm5.wav"))
    f0 = np.full(500, 200.0)
    h1, h2, h4 = get_h1_h2_h4(y, fs, f0)
    assert h1.shape == h2.shape == h4.shape == (500,)
    mid = slice(150, 350)
    for h in (h1, h2, h4):
        assert not np.isnan(h[mid]).any()
        assert (h[mid] > -120).all() and (h[mid] < 120).all()
    # 谐波串幅度递减 → H1 > H2 > H4（中位数，稳健比较）
    assert np.median(h1[mid]) > np.median(h2[mid]) > np.median(h4[mid])

    f0 = np.full(1000, 100.0)
    f0[500] = np.nan

    assert np.isnan(h1[500]) and np.isnan(h2[500]) and np.isnan(h4[500])

### 8.1 fminsearchbnd.m 核对（§7 停报项：无异议）

逐段读完蓝本 304 行，确认与 §2 规格一致：
- **case 3（双有限界）**：初值反变换 `x0u = 2π + asin(clamp(2(x0-LB)/(UB-LB)-1, -1, 1))`（L165-168，含 clamp）；实域变换 `xtrans = (sin(x)+1)/2*(UB-LB)+LB` 后 `max(LB, min(UB, ·))`（L282-285）。
- **蓝本的 BoundClass 0/1/2/4 与 ±Inf 分支**：本项目不需要（两界均有限），未实现；两界非有限时 **raise**（§2 要求）。
- **输出打包**：蓝本 `[xu,fval,...] = fminsearch(...)` 后 `x=xtransform(xu)`（L226-229）→ 本实现返回 `(xtrans(res.x[0]), res.fun)`，一致。
- **无 clamp/NaN 之外的隐藏细节**；未触发停报。

### 8.2 卡缺陷①：`test_unimodal_cosine` 数学错误（§2 测试锚点）

- **卡断言**：`fminsearchbnd(cos, 3, 2, 4)` 应 `abs(x-4)<1e-2`，注释称「cos 在 [2,4] 内最小于 3π/2≈4.712 不在窗内 → 最小在边界 4」。
- **数学事实**：**3π/2 是 cos 的过零点，不是极小点**；cos 的极小点在 π、3π…（cos=−1）。[2,4] **包含 π≈3.14159**，故全局最小在 **x=π**（值 −1），非边界 4。稠密扫描（200001 点）确认最小点 x=3.14159。
- **判定**：实现（收敛到 π）**数学正确**，卡测试断言错误。按 §8「实现正确即不停报」最小修正为 `abs(x - np.pi) < 1e-2 and abs(val - (-1.0)) < 1e-6`。

### 8.3 卡缺陷②：`test_h1h2h4_edge_frames_nan` 帧数错误（§4 测试）

- **卡断言**：`np.isnan(h1[:20]).all()`，注释「±1.5 周期=±240 样本=±15 帧，**留裕量断 20**」。
- **矛盾**：15 < 20，「留裕量」方向反了——断 20 会包含第 16–20 帧（有效）。实测**前 15 帧 NaN**（idx 0–14），idx 15 起有效（与 B1 Energy 的 ±2.5 周期=25 帧完全对称的算法）。
- **修正**：`h1[:15]` + `assert not np.isnan(h1[15])`。
