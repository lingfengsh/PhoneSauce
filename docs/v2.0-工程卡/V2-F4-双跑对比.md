# V2-F4：双跑对比工具（1.2 Praat 引擎 vs 2.0 pysauce）

> 难度：中。前置：V2-F3。
> 背景（用户定案）：2.0 独立成套的目的之一 = **方便比较不同算法的计算结果**。

## 0. 目标一句话

同一批 wav 一键双跑：1.2 Praat 脚本链 vs pysauce 各引擎，输出并排差异表（CSV + vs 页预览），差异统计（每列有效帧数、均值差、最大绝对差）。

## 2. 规格

### compare.py
```python
def compare_files(praat_tsv: str, pysauce_tsv: str, tol: float = 1e-6) -> dict:
    """读两份 out.tsv（1.2 引擎产出 / pysauce 产出），按文件名+时间轴对齐：

    返回 {"per_column": [{col, n_overlap, mean_diff, max_abs_diff, corr}, ...],
          "files": [...], "notes": [...]}
    - 1.2 列名 → 2.0 列名映射表内置（1.2 的 our 参数名 vs VS 列名，施工者
      从 ps-shell-v2/ui/vs.js 的 VS_PARAMS 映射表抄，逐条列进报告）；
    - 对不上的列进 notes（"1.2 无对应列" / "语义不同仅并列展示"——
      已知两者真正等价 ≈3 项，本工具是对比参考不是正确性判定）；
    - 时间轴对齐：1.2 与 pysauce 的帧网格差异按最近邻帧配对（容差 2ms），
      配对率 < 50% 的文件记 notes。
    """
```

### /api/compare（server.py）
- 请求：`{"values": {...}, "files": [...]}`（复用 vs 页的 values；固定双跑：先按 1.2 链跑一遍产 out_praat.tsv，再按 pysauce 跑一遍产 out_pysauce.tsv，然后调 compare_files）。
- 响应：`{"ok": true, "praatPath": ..., "pysaucePath": ..., "compare": {...}}`。
- **必须复用 job 机制**（两轮运行耗时同批量）；禁止在 handler 线程直跑。

### vs 页
- cmdbar 新增按钮「双跑对比」→ 走 validate（pysauce 校验）→ POST /api/compare → 结果掩模显示：每列一行（列名 / 重叠帧数 / 平均差 / 最大差 / 相关系数），顶部摘要（可比列数、notes 条数），「导出对比 CSV」按钮（把 per_column 与两份 tsv 的文件级并排写到 `outputDir/compare_时间戳.csv`）。
- **引擎维度对比（本卡补充，对应 F1 §0c）**：对比表须显示本次双跑的**基准引擎**（`_meta.f0_algorithm`/`fmt_algorithm`）；并提供快捷对比"同一 wav、`fmt_algorithm=praat` vs `=snack`"（即两套引擎结果并列）——这正是用户"比较不同算法计算结果"的核心诉求，**引擎差异而非 1.2/2.0 差异**才是本工具的主要价值。

## 2b. 定位澄清（必读，防误用）

本工具**不是**"2.0 正确性验证器"：1.2 走 Praat 脚本、2.0 走 VS 算法，**两者真正等价仅约 3 项**（前期调研结论）。因此：
- 差异表是**预期差异的呈现**，不是 bug 清单；
- 用户真正的用途是**横向比较不同引擎/不同算法口径**（Praat vs Snack vs VS 算法），据此选择研究口径；
- 验收时**不得**以"差异小"为通过标准；应检查"差异是否符合已知算法特性"（如 Praat 与 Snack 共振峰差异应在合理范围）。

## 3. 测试（`tests/test_compare.py`，原样照抄）

```python
# -*- coding: utf-8 -*-
"""compare 纯函数测试（不起服务、不跑引擎）。禁改。"""
import os

import numpy as np

from backend.pysauce.compare import compare_files


def _write_tsv(path, cols, rows):
    with open(path, "w", encoding="utf-8") as f:
        f.write("\t".join(["file", "time"] + cols) + "\n")
        for r in rows:
            f.write("\t".join(str(x) for x in r) + "\n")


def test_compare_aligns_and_stats(tmp_path):
    a = os.path.join(str(tmp_path), "a.tsv")
    b = os.path.join(str(tmp_path), "b.tsv")
    _write_tsv(a, ["Energy"], [["x.wav", 0.0, 10.0], ["x.wav", 0.001, 12.0]])
    _write_tsv(b, ["Energy"], [["x.wav", 0.0, 11.0], ["x.wav", 0.001, 10.0]])
    out = compare_files(a, b)
    col = out["per_column"][0]
    assert col["n_overlap"] == 2
    assert abs(col["mean_diff"] - (-0.5)) < 1e-9      # a-b 平均
    assert abs(col["max_abs_diff"] - 2.0) < 1e-9


def test_compare_missing_column_noted(tmp_path):
    a = os.path.join(str(tmp_path), "a.tsv")
    b = os.path.join(str(tmp_path), "b.tsv")
    _write_tsv(a, ["Energy"], [["x.wav", 0.0, 10.0]])
    _write_tsv(b, ["CPP"], [["x.wav", 0.0, 5.0]])
    out = compare_files(a, b)
    assert out["notes"]                                # 无交集列 → notes
```

### 7.2 关键实现
- **1.2→2.0 列名映射**（`COLUMN_MAP_12_TO_20`，来源 `scripts/initiateTable.praat` 的
  firstLine$ vs `output_cols.py` OUTPUT_COLS）：
  - 异名：`f0→pF0`、`F1..3→pF1..3`、`B1..3→pB1..3`、`intensity→Energy`、`H4-2Ku→H42Ku`、`t→time`

- **对齐**：`_align_rows` 按 `(file, time)` 最近邻配对（容差 2ms）；`pair_ratio` = 配对数/1.2 帧数。
- **差异口径**：`mean_diff = mean(2.0 − 1.2)`（负值=2.0 偏小）；`max_abs_diff = max|2.0−1.2|`；

  落 `compare_<时间戳>.csv`。

### 7.5 已知限制（非本卡 bug）
- 1.2 腿受「读缓存」影响：音频目录若已有 `measure/` 对象，Praat 会优先读盘 → 换参数重跑前
  须清 measure/（1.2 既有行为，见项目 MEMORY）。
- 两版帧网格不同（1.2 按 pitch 帧、2.0 固定 1ms），配对率与重叠帧数受此影响；
  H1c 家族在边界帧常为 None，故重叠少属正常。
