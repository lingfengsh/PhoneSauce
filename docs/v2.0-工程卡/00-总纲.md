## 0. 本工程是什么、不是什么

**是什么**：新建独立目录 `ps-shell-v2/`，把 VoiceSauce 的 MATLAB 测量算法逐行复刻为 Python（NumPy/SciPy），接到 VoiceSauce 界面（vs 页）的按钮与选择上。1.2 的 `ps-shell/` **一个字都不动**，两版并存，方便对比不同算法的计算结果。

**不是什么**：
- 不是重写向导。向导五步（选音频→要测什么→批量运行→查看结果→导出）在 v2 里仍走原 Praat 脚本（`scripts/` 25 个），零改动。
- 不是照抄上游 Praat 脚本。算法唯一依据是 `refs/voicesauce-v137/` 的 MATLAB 源码。v1.2 Praat 脚本值仅作对照参考（此前调研：两者真正等价的只有 3 项）。
- 不引入 Numba / C / Rust。语言定案：**Python + NumPy/SciPy 向量化**（已拍板，不要重新讨论）。

## 3. 施工协议（每张卡都走这五步，一步不跳）

1. **领卡**：一次只领一张卡。读卡 + 读卡中列出的蓝本文件，列出「预实施检查单」（将创建/修改的文件清单）。
2. **预检**：核对依赖卡是否已完成（跑其验收命令应全绿）；核对文件白名单外没有需要动的文件。
3. **实施**：只创建/修改卡中白名单文件。每翻译一段 MATLAB，在 Python 侧写注释 `# MT-L<起始行>-<结束行>: <MATLAB 原句要点>`。
4. **自检**：跑卡中「验收」一节的全部命令，全绿；对照验收标准逐条打勾。
5. **交付报告**（固定格式，缺一不收）：

   - 停报项（如有）

## 6c. 基准引擎（硬性，2026-10-26 用户提出）

下游算法（H1/A1/2K/CPP/HNR/SoE）**不直接吃某引擎列**，而是吃 `parse_f0(matdata, f0_algorithm)` / `parse_fmt(matdata, fmt_algorithm)`（VS 原生 `func_parseF0`/`func_parseFMT` 机制）：
- `pitch_engine`/`formant_engine` = **算哪几套**（可多套并存，分列输出）；
- `f0_algorithm`/`fmt_algorithm` = **下游用哪套**（用户明确选择）；
- 指定引擎不存在 → 空 → 相关列 NaN（**不自动回退**，照 VS 行为）。
- 详细规格：F1 §0c、规划文档 §五之二。

## 7. MATLAB → NumPy 翻译规则（全局有效，A3 卡提供基础设施）

| # | 规则 | 说明 |
|---|---|---|
| R1 | **round = 四舍五入远离零** | MATLAB `round(2.5)=3, round(-2.5)=-3`；NumPy `np.round` 是银行家舍入（`round(2.5)=2`）——必须用 `matlang.mround` |
| R2 | **索引 1-based，含端点** | `x(3:7)` → `x[2:7]`；`x(end)` → `x[-1]`。翻译时先在草稿上换算，禁止直接照抄数字 |
| R3 | **find 空集** | MATLAB `find(...)` 空时后续 `max/min/mean` 返回空矩阵不报错，Python 会崩——每个 find 后必须判空走 MATLAB 同款空分支（读蓝本看空分支怎么走） |
| R4 | **列向量 = 1-D float64** | 统一 `np.ndarray(dtype=np.float64)` 一维；二维只用于帧矩阵（`matlang.frameify`） |
| R5 | **未定义值** | MATLAB `NaN` 语义 → Python `np.nan`；输出表写 `--undefined--`（沿用 1.2 约定）。禁止用 0、-1、None 占位 |
| R6 | **逐段注释** | 每段 Python 注释 `# MT-L<行号>` 对应蓝本行号，验收员据此逐段核对 |
| R7 | **整除/幂** | `/` 在 MATLAB 对整数也返回浮点 → Python 用 `/` 不用 `//`；`^` → `**` |
| R8 | **循环变量与预分配** | MATLAB `zeros(1,n)` → `np.zeros(n)`；循环能向量化才向量化（卡中允许时），否则老实写 for——正确性优先 |
| R9 | **字符串比较** | `strcmp` → `==`（str）；`strncmp` → 切片比较 |
| R10 | **filter/递推** | `filter(b,a,x)` → `scipy.signal.lfilter(b, a, x)`（注意 MATLAB 分子分母顺序与 scipy 一致：b 前 a 后） |
| R11 | **表达基底分层（版权合规）** | ① 开工任何算法模块前，先查 `docs/v2.0-版权合规评估与声明.md` §五分层表：SHRP/SHR、F0 的 Praat 包装、谐波幅度属 **A 层（OS-P 覆盖）**——**文件级 vendored**：把 opensauce-python 对应源文件（含其内部依赖）原样拷入 `pysauce/_vendor/`（osp_ 前缀改名，Apache-2.0 头照带，改动逐条记 modified 头），数值行为按蓝本仲裁；适配层只做签名/网格对齐。**禁止改标 MIT、禁止裸拷贝无头**。其余模块属 **B 层**——按论文思想独立实现，MATLAB 蓝本仅用于行为语义仲裁（参数/系数/分支/列名）。② **禁止把 MATLAB 源码语句逐行直译为 Python**；`# MT-L<行号>` 注释只写行为要点（paraphrase），禁止抄 MATLAB 原句 |

**traps 清单（历史踩坑，逐卡注意）**：`zero#(0)` 越界（MATLAB 空数组索引不崩，Python 崩）；`undefined < 500` 在 MATLAB 返回 false、NaN 同样返回 False（巧合一致，但 `NaN <> 0` 为 True 与 `undefined <> 0` 为 True 一致）；`log(0) = -Inf` 两边一致，但后续 `10*(-Inf)` 传播到输出要保留 NaN/Inf 语义。

## 6. 数值验证策略（无 MATLAB Runtime 的替代锚，按可信度排序）

1. **手算锚点**：合成信号（正弦、已知幅度谐波串）的解析解。A2 卡生成，锚点写死在 `tests/fixtures/expected/`。
2. **回归快照**：每个算法函数首次通过验收后，验收员将其对 `samples/` 30 wav 的输出冻结为快照 `tests/fixtures/snapshots/<name>.json`。此后任何改动必须保持快照不变（容差 1e-9），漂移即停报。
3. **物理区间 sanity**：正常语音 HNR05 ≈ 0–20 dB、CPP ≈ 0–20 dB、SHR ≈ 0–1、Energy > 0 等粗检。
4. **opensauce-python 交叉**（D2/M4 阶段）：同批样本对比出容差表，作参考报告不作硬门槛。
5. **v1.2 Praat 引擎对照**：仅参考（等价项 ≈ 3）。
