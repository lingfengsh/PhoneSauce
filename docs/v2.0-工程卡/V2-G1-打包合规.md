**已安装但无人 import** 的重型包一并收集：torch 365M + cv2 99M + imageio_ffmpeg 84M + onnxruntime 29M + torchvision 12M ≈ **590 MB 全是垃圾**

→ 在 spec `excludes` 显式排除后：**890 MB → 144 MB**（+praat.exe 97M = 最终 240 MB），构建耗时 509s → 43s。
`_soundfile_data` 仍在包内，STRAIGHT 冒烟通过 → 排除项无误伤。
