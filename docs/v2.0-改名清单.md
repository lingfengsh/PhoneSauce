## 二、需要你决策 / 操作的外部改名（仓库 + DOI）

以下三处**不在代码内**，改名会造成外部链接变化，需你确认后再执行。

### 步骤 1 · GitHub 仓库改名（可选，影响 star/fork/链接）
1. 打开 <https://github.com/lingfengsh/PhoneSauce/settings>
2. **Repository name** 改为 `PhoneSauce` → Rename。
3. GitHub 会自动重定向旧地址（`praatsauce-shell` → 新名），但**外部引用的 raw 链接与 clone 命令会失效**。
4. 改名后本地需同步远程地址：
   ```bash
   git remote set-url origin https://github.com/lingfengsh/PhoneSauce.git
   ```
5. 同步更新仓库内引用（这几处目前仍写旧仓库名，属 1.2 发布产物，**建议随 2.0 正式版一起改**）：
   - `README.md` L7 / L140 / L176 / L177 / L293
   - `CITATION.cff` L34 / L35
   - `THIRD-PARTY-NOTICES.md`（若有仓库地址）
   - `docs/v2.0-使用说明增补.md`（引用地址）

### 步骤 2 · Zenodo DOI
- **概念 DOI 不变**：`10.5281/zenodo.23463195`（始终指向最新版本，论文引用继续用这个）。
- **版本 DOI 新增**：2.0 发 GitHub Release 后，Zenodo 自动归档并生成一个新的版本 DOI。
- **无需改任何东西** —— Zenodo 靠 GitHub Release 触发，仓库改名不影响已启用状态（Zenodo 会跟随重定向）。
- ⚠️ Zenodo 要求：先在 `zenodo.org/account/settings/github/` 里确认仓库仍处 "ON" 状态；改名后如列表消失，重新启用一次。

### 步骤 3 · 项目名（CITATION / README / 关于页）
- 2.0 的 **CITATION.cff** 建议新建一份 2.0 版（或更新 title/abstract/version），
  与 1.2 区分：
  - `title`: "PhoneSauce 嗓音分析助手：多引擎中文嗓音（发声态）声学分析工具"
  - `version`: "2.0.0"
  - `abstract`: 更新为多引擎描述（Praat / pysauce / Snack 复刻 / STRAIGHT 近似）
- README 根文件同理，建议在 2.0 正式发布时整体更新（当前仍是 1.2 正文）。
