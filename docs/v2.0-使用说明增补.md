## 一、本版新增能力（相对 1.2）

1. **VoiceSauce 算法原生实现（无需 MATLAB Runtime）**
   2.0 按公开论文独立实现了 VoiceSauce v1.37 的核心参数提取算法（Python + NumPy/SciPy），
   不再依赖 MATLAB 或 MCR 运行时。**声明**：本实现为算法语义的独立实现，
   未包含或逐字翻译 VoiceSauce（© UCLA SPAPL）的 MATLAB 源码。

2. **可切换的 F0 / 共振峰基准引擎**
   - F0 与共振峰**各自**可指定一个基准引擎（不共用），可选：
     `Praat` / `Snack` / `STRAIGHT` / `Other（外部文件）`。
   - **向导界面**默认 Praat；**vs 界面**默认 VoiceSauce 原生默认（straight / snack）。
   - 一次运行只算一套基准；换基准后若该套结果尚未计算，会即时补算。
   - 结果文件名带双前缀 `<F0引擎>_<共振峰引擎>_out.tsv` 以区分不同基准的组合。
   - 导出时若同一音频目录存在多套结果，会询问导出哪一套。

3. **双跑对比（1.2 vs 2.0）**
   vs 界面提供「对比」按钮：同一样本分别用 1.2（Praat 脚本）与 2.0（pysauce）各跑一遍，
   逐列给出均值差 / 最大绝对差 / 相关系数，导出为 `compare_<时间戳>.csv`。

## 二、引擎说明与诚实声明

| 引擎 | 实现方式 | 数值可信度声明 |
|---|---|---|
| Praat | 调用本机 praat.exe 跑 PraatSauce 脚本 | 与 1.2 一致 |
| Snack | **RAPT（Talkin 1995）+ LPC 自相关法** 算法复刻 | 算法等价实现，**非**真 Snack 二进制，数值不逐位相同 |
| STRAIGHT | pylstraight（legacy 近似） | **近似**，非原 STRAIGHT 逐位一致 |
| Other | 纯解析外部文件（F0/共振峰轨迹） | 原样读取，不做插值 |

> 引用本程序的 Snack / STRAIGHT 结果时，请注明其为「RAPT/LPC 算法复刻」/「legacy 近似」。

## 三、参数与输出列

- 输出列采用 **VoiceSauce 原生 67 个显示名**（如 `H1* (H1c)`、`H2K (H2K)`），
  机器列名为括号内的短名。
- 未定义值写为 `--undefined--`（不是 0）：出现在无谐波、无 SoE 等情形。
